# N-03 · verify_grounding — 책임 등록

> **상태:** 상세 계약·구현 미확정. 기존 [Small Node LIST](../query-agent-node-list.md)의 **역할과 최소 입출력만 별도 문서로 분리**한 틀이야.

## 1. 단일 책임

주장·판정·비교 결과와 원문 근거의 정합성 검사.

## 2. 최소 입출력 (개념 수준)

| 구분 | 현재 등록된 내용 |
|---|---|
| 입력 | 결과 초안·EvidenceBundle |
| 출력 | VerificationReport |

## 3. 후속 검토

- 내부 함수/모델/도구 사용 여부, 구체 데이터 필드
- 오류·실패 처리·완료 기준 및 테스트

**경계:** 업무별 노드 조합·Big Node 조건부 엣지는 이 문서에 두지 않는다. 내부 보조 함수는 Tiny Node로 분할하지 않는다.
