# T-04 · Claim Verification — 개별 주장 검증

> **상태:** 후속 계획 / 상세 워크플로 및 Small Node 조합 **미확정**. MVP에서는 실행하지 않는다.

[Big Node 목록](README.md) · [Query Agent 상위 구조](../query-agent-mvp.md) · [Small Node 목록](../small-nodes/README.md)

## 목적

문서의 개별 주장에 대한 지지·반박 근거, 정합성, 검증 가능 범위를 살핀다.

## 향후 설계 쟁점

- 주장 단위 분해, 근거·반증의 충분성, 출처 독립성
- [T-02 Criteria Review](T-02.md)와의 판정/검증 기능 중복
- 문서에 있는 내용의 지지 여부와 외부 세계의 사실 검증 구별

## 연결될 Small Node

**미정.** 새 노드나 기존 노드 조합, 조건부 엣지를 지금 확정하지 않는다. [N-10](../small-nodes/N-10.md)은 MVP에서 T-04로 라우팅하지 않는다.
