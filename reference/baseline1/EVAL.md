# baseline-1 평가 방법과 결과

## 평가 방법

평가 러너는 [scripts/run_eval.py](../../scripts/run_eval.py)다. `--version v23`과 세트 이름을 지정하면 파이프라인을 실행하고 문항별 로그와 집계를 `runs/<run-id>/`에 쓴다. 각 반복은 파이프라인과 색인을 새로 만들며, 색인 구축 시간은 응답시간에서 제외된다. 이 문서는 이미 저장된 로그만 옮겼으며, 여기서 파이프라인·평가·API를 실행하지 않았다.

```powershell
uv run python scripts/run_eval.py --version v23 --sets sample3,hard20,holdout10,drive20 --repeat 1
uv run python scripts/run_eval.py --version v23 --sets sample3 --repeat 3
```

세트는 공식 샘플 `sample3` 3문항, `hard20` 20문항, `holdout10` 10문항, `drive20` 20문항이다. 합계는 53문항이다. 보고서 §33은 hard20·holdout10·drive20을 개발에 사용한 세트로 명시한다. 따라서 이 측정치를 독립적인 일반화 성능으로 해석하지 않는다.

러너의 고정 판정 프롬프트(`scripts/run_eval.py:40–42`)는 다음과 같다.

> 정답과 예측 답변을 비교하세요. 표현이 달라도 핵심 정보(수치·날짜·대상·조건)가 모두 일치하면 정답입니다.
> 부분점수는 없습니다. 하나라도 빠지거나 틀리면 오답입니다.

판정은 `Verdict(correct, reason)` 구조를 사용한다. 시간 점수는 [scripts/run_eval.py](../../scripts/run_eval.py)의 `time_score` 및 [README_LOCAL.md](../../README_LOCAL.md)에 따라 **정답 문항만** 계산한다. 5초 이하는 0.4점, 5초 초과 10초 미만은 `0.4 − 0.08 × (응답초 − 5)`점, 10초 이상은 0점이다. 오답은 응답시간과 무관하게 0점이다.

## 실패 유형

아래는 보고서 §37 및 baseline 작업계획서에 따라 유형과 세트·문항 ID만 기록한다.

| 유형 | 세트와 문항 ID |
|---|---|
| 표 열·병합 셀 오독 | holdout10 #6; drive20 #17, #19 |
| 검색 누락 또는 검색 시간 제한 | drive20 #12, #20 |
| 조건·세부 항목 누락 | drive20 #4, #7, #14, #18 |
| 기타·미분류 | holdout10 #2; drive20 #11, #15, #16 |

정답 개수만으로는 상쇄된 개별 회귀를 볼 수 있으므로, v22와의 차이는 [REPORT_중간평가_진행상황.md §36–37](../../REPORT_중간평가_진행상황.md)에서 함께 확인한다. 범위·응답 지연·judge 변동 때문에 개선을 특정 변경의 인과 효과로 단정하지 않는다.
