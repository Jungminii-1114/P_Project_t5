# 프로필별 파싱 출력 비교

같은 로컬 원문 5개를 `gachon_2027`과 중립 `ParserConfig()`로 실행했다. 출처는 [동결 manifest](../snapshots/manifest.json), [프로필 manifest](../snapshots/generic_gachon_2027/manifest.json), [중립 manifest](../snapshots/generic_neutral/manifest.json)다. jsonl 본문은 Git에서 제외하며 CLI로 재생성한다. 비교에는 API를 사용하지 않았다.

| 항목 | 문서군 프로필 | 중립 기본값 |
|---|---:|---:|
| 추출 요소 | 382 | 382 |
| 청크 / 문맥 청크 | 513 / 513 | 513 / 513 |
| 표 청크 | 235 | 235 |
| 행 요약이 있는 표 청크 | 61 | 63 |
| 표제가 붙은 표 청크 | 235 | 235 |
| 일정 전용 표제가 붙은 청크 | 26 | 0 |

문서군 프로필은 동결 스냅샷의 요소 382개, 청크 513개, 문맥 청크 513개와 순서·`page_content`·메타데이터가 모두 같다. 비교에서 제외한 것은 범용판이 추가한 `locator`뿐이다. 프로필과 중립 설정 사이에서는 표 행 요약 46개와 문맥 첫 줄의 표제 81개가 달랐다. 청킹 길이와 원문 `raw`는 동일했다.

문서 제목은 5개 모두 같았다. 중립 설정의 번호 제거·밑줄 정리가 이 문서군의 명시적 제목 매핑과 같은 결과를 냈다.

| 원본 접두사 | 두 설정에서 공통으로 나온 제목 |
|---|---|
| 01 | 2027학년도 재외국민 모집요강 |
| 02 | 2027학년도 지역의사선발전형 안내 |
| 03 | 2027학년도 수시 모집요강 |
| 04 | 2027학년도 정시 모집요강 |
| 05 | 2027학년도 수시 면접고사 일정 |

차이가 큰 예시의 짧은 발췌다. HWP의 p.N은 실제 페이지가 아니라 기존 호환 위치 값이다.

| 청크·위치 | 문서군 프로필 | 중립 기본값 |
|---|---|---|
| `chunk_id=30`, 01 p.17 | 행 요약 없음 | `- 입학원서: 2027학년도 재외국민 제출서류 목록=○, …`처럼 반복 헤더의 값 쌍이 생성됨 |
| `chunk_id=1`, 01 p.3 | `- 인문 경영학과: 최대모집 가능인원=15, 모집인원=16` 등 행 요약 | 행 요약 없음 |
| `chunk_id=290`, 03 p.34 | `표제: 면접/전형 일정`, 행 요약 있음 | `표제: 구분`, 행 요약 없음 |

빈 헤더 키워드는 기존 `start=1` 경로를 쓰고, 빈 행 라벨 키워드는 기존 roster 라벨 추출 경로를 쓴다. 일정 패턴을 비우면 기존 일반 표제 경로를 사용한다. 위 차이는 설정 출처를 분리한 결과이며 표 판독 품질이나 RAG 정확도의 개선을 뜻하지 않는다. 범용판 RAG 평가는 [B7](../../../BACKLOG.md)이다.
